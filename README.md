# 運動紀錄 workout-records

iPhone 用的 PWA，記錄飯後運動、有氧運動與肌力訓練，判斷本週是否達標。所有資料只存在手機的 IndexedDB，不上傳任何地方。

## 檔案

| 檔案 | 用途 |
|---|---|
| core.js | 純邏輯：日期（本地時間）、目標計算、計分、計步、強度判定、節拍器排程、備份驗證 |
| db.js | IndexedDB 存取（records、kv），從不刪除舊資料 |
| app.js | 介面、計時、動作感測、節拍器、螢幕常亮、匯出匯入 |
| sw.js | 離線快取。**改任何檔案後 CACHE_NAME 版號加一** |
| tests/run_tests.sh | 一鍵測試：核心單元測試（兩個時區）+ puppeteer 端到端 |

## 規則

- 有氧目標：每週 150 分鐘；BMI 24 以上 250 分鐘；未滿 18 歲 420 分鐘。高強度 1 分鐘算 2 分鐘。
- 輕鬆強度（步頻不到 100）一律不計入有氧分鐘數，飯後運動也一樣。
- 飯後運動：每天 2 次，每次至少 15 分鐘才算一次（設定可改），不論強度；一天多做不能補另一天。
- 肌力：每週 2 天。
- 強度：項目有預設強度；只有勾「依步頻判斷」的項目（健走、飯後散步）在動作感測涵蓋 50% 以上時間時自動用步頻判斷（100/130 步/分）。超慢跑步頻高但預設中強度。
- 進行中的運動存在 localStorage `wr.session`，App 被系統關掉後重開會接回。
- 熱量在存檔當下用當時體重計算並存入紀錄，之後改體重不影響舊紀錄。

## iOS 限制

- 網頁讀不到 HealthKit；鎖屏或切到背景時讀不到動作感測（不計步）。計時用時間戳記，不受影響。
- 螢幕常亮預設關閉，只用 Screen Wake Lock（不用影片備援）。
- 節拍聲：鎖屏後網頁程式會被凍結，所以依 BPM 預先產生 60 秒（整數拍）的 WAV，用 `<audio loop>` 循環播放，並設定 MediaSession 讓鎖屏畫面有播放、暫停鍵。`navigator.audioSession.type = "playback"`（使用者選定）：鎖屏、靜音開關都不影響，但會暫停其他 App 的音樂。iOS 忽略 `audio.volume`，音量直接寫進樣本。
