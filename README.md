# 運動紀錄 workout-records

iPhone 用的 PWA，記錄飯後運動、有氧運動與肌力訓練，判斷本週是否達標。所有資料只存在手機的 IndexedDB，不上傳任何地方。

## 檔案

| 檔案 | 用途 |
|---|---|
| core.js | 純邏輯：日期（本地時間）、目標計算、計分、強度預選、節拍器音軌、備份驗證 |
| db.js | IndexedDB 存取（records、kv），從不刪除舊資料 |
| app.js | 介面、計時、節拍器、匯出匯入 |
| sw.js | 離線快取。**改任何檔案後 CACHE_NAME 版號加一** |
| tests/run_tests.sh | 一鍵測試：核心單元測試（兩個時區）+ puppeteer 端到端 |

## 規則

- 有氧目標：每週 150 分鐘；BMI 24 以上 250 分鐘；未滿 18 歲 420 分鐘。高強度 1 分鐘算 2 分鐘。
- 輕鬆強度（步頻不到 100）一律不計入有氧分鐘數，飯後運動也一樣。
- 飯後運動：每天 2 次，每次至少 15 分鐘才算一次（設定可改），不論強度；一天多做不能補另一天。
- 肌力：每週 2 天。
- 強度：結束時由使用者選。走路類（健走、飯後散步）不預選，每分鐘不到 100 步選輕鬆（100/130 步/分為中/高強度門檻）；其他項目預選預設強度。計步已移除（iPhone 實測準確度不足以參考），也不再要求動作感測權限。
- 進行中的運動存在 localStorage `wr.session`，App 被系統關掉後重開會接回。
- 熱量在存檔當下用當時體重計算並存入紀錄，之後改體重不影響舊紀錄。

## iOS 限制

- 網頁讀不到 HealthKit。計時用時間戳記，鎖屏或 App 被關掉都不受影響。
- 節拍聲：依 BPM 預先產生 60 秒（整數拍）的滴答聲，交給 Web Audio `AudioBufferSourceNode`（`loop = true`）在音訊執行緒原生循環，不靠 JS 計時、接縫不中斷（舊版 `<audio loop>` 在 iOS 每分鐘接縫會停約 1 秒，已棄用）。`navigator.audioSession.type = "playback"`（使用者選定）：靜音開關不影響，但會暫停其他 App 的音樂。鎖屏時 iOS 是否讓 AudioContext 持續需實機確認；回到前景時 App 會比對音訊時鐘與實際時間，提示背景期間是否中斷。
